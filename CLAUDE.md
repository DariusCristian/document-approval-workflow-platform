# CLAUDE.md

## Rules

- Commit only when I say the step works (e.g. "commit it"), never automatically right after making changes.
- Use one commit per step, with a short, clear message in the imperative (e.g. "Add session-based login").
- Never add Co-Authored-By lines or "Generated with Claude Code" to commit messages.
- Never run `git push`. I push myself.
- After each change, explain in simple terms what you changed, in which files, and why.
